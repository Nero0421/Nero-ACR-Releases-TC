# Nero-ACR-Releases-TC

Nero ACR 繁中服(TC)混淆成品发布仓库，蝰蛇(VPR)、镰刀(RPR)、武僧(MNK)、武士(SAM)四职业合包。

当前版本：1.0.5.6，适配 PromeRotation 1.3.1.1（apiVersion 13）。

- **上天自动排轴支持同步等级和多怪场景。** 镰刀、蝰蛇、武僧、武士会按当前等级能用的技能、资源上限和敌人数量计算。
- **Boss 上天时，有小怪可打也会继续规划。** 将这段时间能打出的伤害、获得的资源，以及落地后的输出一并纳入计算。
- **新增「Nero/预计近身小怪区间」节点。** 时间轴作者可单独填写小怪出现与结束时间、数量和可选种类 ID；QT、等待和分支继续写在原轴里。
- **开爆发前检查能否完整收尾。** 自动安排时会把镰刀附体及后续收招、蝰蛇祖灵及续击、武僧震脚三拳与必杀、武士明镜及居合／奥义回返算进去，时间不足时暂缓开启，减少打到一半 Boss 上天的情况。作者主动关闭 QT、Hold 或精修排轴仍优先。
- **改善频繁移动时的重算和等待。** 减少无效重算；连续重算造成的资源技能临时等待最多 500 毫秒，随后恢复原循环并继续后台计算。临近上天的收尾保护仍生效。
- 保留每段最多 10 分钟详细推演、作者自填容错，以及按各次落地后 20 秒依次交接的规则。国服与繁中服四职业同版更新；已通过离线与混淆包验证，实战表现仍需游戏内反馈。

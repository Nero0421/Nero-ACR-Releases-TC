# Nero-ACR-Releases-TC

Nero ACR 繁中服(TC)混淆成品发布仓库，十二职业合包：蝰蛇(VPR)、镰刀(RPR)、武僧(MNK)、武士(SAM)、龙骑(DRG)、舞者(DNC)、赤魔(RDM)、黑魔(BLM)、画家(PCT)、召唤(SMN)、机工士(MCH)、吟游诗人(BRD)。

当前版本：1.0.8.7，适配 PromeRotation 1.3.1.1（apiVersion 13）。

- 1.0.8.7 十二職業戰鬥錄製支援逐次查看選招理由、目標與動作確認。每場生成復盤報告，可用同一份錄製比較兩個版本。回報問題時請傳送停止錄製後的 .jsonl.gz 原檔，並註明場次和大致時間。
- 蝰蛇依實際出手時間預測靈力，恢復依連段與增益選擇蛇刀，站錯身位時依現有自動真北設定處理。武士依隊伍實際狀況對齊團輔，機工可選擇讓人偶跟隨實際團輔。
- 舞者可依本隊實測校準伶俐預測，並修正四步收尾。詩人可為第二個交戰目標維持雙毒。機工人偶與詩人雙毒預設關閉，舞者校準預設開啟，均可在職業戰鬥設定中調整。
- 調整插技與真北的出手時機，並修正部分技能等級辨識、地區技能資料與舊設定清理問題。
- 1.0.8.6 同版本修复：解决欢迎动画中 Nero 等英文称呼缺失的问题；异常字体缓存会自动重建，正常缓存继续保留。
- 1.0.8.6 更新粒子王冠主界面、分页导航和 QT/热键控件；新增可自定义的欢迎动画，当前欢迎语缓存可跨重启保留；固定标题字图内嵌，改善字体清晰度、边沿动效及输入体验。战斗逻辑保持 1.0.8.5。
- 1.0.8.5 蝰蛇修复真北生效时仍按站位换刀，新增默认开启的「蛇刀身位自适应」设置；镰刀选刀恢复早期顺序并保留旧分支；机工补全团灭/加载期间的当前对象读取保护与 AOE 采样。
- 1.0.8.4 机工增加团灭暗转期间失效目标状态读取保护，避免未处理异常导致游戏退出；优化日随濒死小怪满热防溢出与 Boss 收尾资源保留。
- 1.0.8.3 赤魔新增 50～100 魔三连启动魔元阈值（默认 50，按黑/白魔元较低一侧判断），设置页与时间轴「循环参数覆盖」参数 `melee_mana_threshold` 均可调整。
- 1.0.8.2 武僧新增「红莲对齐120」QT（义结金兰剩余 CD＜30 秒时红莲等待，≥30 秒不管控）；设置主窗、QT 窗口、热键窗口支持独立 0～100% 透明度调整。
- 1.0.8.1 黑魔修复移动火尾误判导致的空交即刻；新增「移动瞬发」QT，支持关闭移动中的自动 GCD 与移动缺口触发的三连/即刻。
- 1.0.8.0 机工修复倒数/先开怪起手被废弃（允许外部先手已消耗工具与电量、已耗步骤自愈、起手不再误判为外部起手）；修复超荷后等野火造成整拍空转，GCD 归零可先补野火。
- 1.0.7.9 画家支持 1–100 全等级段：修复 80 级以下同步副本（如白山堡/巴埃萨长城）整循环不出手，低等级按实际解锁打填充/彩绘/重锤/减色/星空。
- 时间轴小数与浮点覆盖、龙骑起手等级回退、黑魔起手总闸、机工预读解耦与量谱修复、舞者宣泄模式，以及目标 HP／循环参数覆盖预测接入。
- 1.0.7.5 新增简中/繁中/日/英界面热切换；时间轴循环参数覆盖与预读变量、目标生命值与武僧震脚条件、保留震脚和绝龙诗起手；龙骑方向后跳落点预览。
- 近期：1.0.7.4 机工冷却读数修复；1.0.7.3 四窗动效与帧开销改版；1.0.7.2 机工起手发呆修复；1.0.7.0 起合包扩至十二职业。
- 已通过双服离线回归、正式编译与混淆包检查；游戏内实测以反馈为准。
